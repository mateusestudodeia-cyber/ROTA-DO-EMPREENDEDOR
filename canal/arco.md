# Arco do Carlos a partir do EP03 (pedido do dono do canal)

**Direção:** o Carlos deixa de ser "o cara das marmitas" e vira um **empreendedor em série**: a cada 2–4 episódios
um empreendimento novo (ou uma tentativa nova), com erros, aprendizado e evolução. Ele **procura crescer, tentar, evoluir**.

## Ingredientes que devem aparecer ao longo dos episódios
1. **Vários empreendimentos diferentes** (fictícios, valores ilustrativos), por exemplo: marmitas (EP01–02) → serviço digital
   (sites/automação para pequenos comércios) → revenda/e-commerce → produto digital → agência/serviço recorrente. Cada um ensina 1 conceito real.
2. **Claude Code como ferramenta do Carlos:** ele usa o Claude Code para criar site, planilha, automação, cobrança, atendimento.
   Mostrar com honestidade: a IA acelera, mas não decide por ele (o erro de julgamento continua sendo do Carlos).
   Citar só o que o Claude Code realmente faz; nada de promessa de "dinheiro fácil".
3. **Livros reais, ideias reais:** ele lê e tenta aplicar (ex.: *Trabalhe 4 Horas por Semana*, Tim Ferriss; *Pai Rico, Pai Pobre*,
   Robert Kiyosaki; *A Startup Enxuta*, Eric Ries; *Receita Previsível*… só livros que existem). Regras: dizer título e autor,
   **parafrasear a ideia central com precisão, sem aspas inventadas** e mostrar o Carlos aplicando (e errando ao aplicar do jeito errado).
4. **Mentores e pessoas de sucesso — FICTÍCIOS.** Não usar pessoas reais (ex.: Alfredo Soares, Tallis Gomes) como personagens com falas
   ou fatos inventados. Criar mentores fictícios inspirados em perfis reais de mercado (o fundador de startup, a dona de rede de varejo,
   o investidor-anjo, o contador veterano), com placa "MENTOR" e nome fictício. Se quiser citar um empresário real, só como
   referência pública e verificável ("li uma entrevista em que X diz Y" apenas com fonte confirmada na hora, ou nenhuma citação).
5. **Evolução visível:** a cada bloco, o Carlos muda (postura, ferramentas, vocabulário), mas segue com falhas humanas (pressa, medo de
   decepcionar, vaidade). Todo avanço custa algo; todo erro tem número em reais.
6. **Ciclos:** tentar → errar → aprender (livro/mentor/dado) → ajustar → resultado honesto → gancho para a próxima tentativa.

## Como usar
- No passo 4.2 (roteiros), ler este arquivo, escolher onde o Carlos está no arco e continuar do gancho do último episódio.
- Registrar em `canal/personagem.json` os novos personagens (mentores) e o que cada um ensinou, para manter a continuidade.
- Novos personagens: mesmo traço palito, com plaquinha do nome; criar tipo novo em `biblioteca/personagens.js` se preciso.
